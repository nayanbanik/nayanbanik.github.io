## What we built

SafeSight AI is a real-time OSHA/ANSI violation detection system. We manually annotated ANSI/OSHA violation images with Roboflow, fine-tuned a YOLO v11x model, and deployed it on a FastAPI-based Microsoft Azure Web App for real-time inference. The cross-platform mobile front end is built with Ionic React and CapacitorJS and hosted on Microsoft Azure Static Web Apps. The model runs as a containerized service with an operator UI, and we built automated evaluation pipelines covering precision, recall, F1, and latency.

The solution was recognised for its business impact, scalability, and real-world applicability in automating compliance tracking for workplace safety.
